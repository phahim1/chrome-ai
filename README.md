# BloomAI - Google Chrome AI

This repository contains a minimal proof-of-concept (POC) for the "BloomAI" project, submitted for the Google Chrome Built-in AI Challenge 2025.

**The full project concept is detailed in the official Devpost submission text.**

## About This POC

This simple `index.html` file demonstrates the ability to call the built-in `Summarizer API` to show the technical feasibility of the project.

## The Full "BloomAI" Concept

BloomAI is an AI-powered educational tool designed to solve a major problem: the gap between memorization and deep understanding. It uses the Chrome Built-in AI APIs to create a "learning ladder" based on Bloom's Taxonomy, guiding a student from basic recall to complex creation, all while ensuring 100% privacy and offline access.
